# Бумажка — «Кто я?»

Онлайн-версия игры «бумажка на лбу»: каждому загадывают слово, все видят чужие слова, кроме своего. Задаёте вопросы «да / нет» и угадываете, кто вы.

**Играть:** https://babaevrafael.github.io/bumazhka/

## Как это работает

- Хост создаёт лобби → получает 5-символьный код и придумывает пароль. Остальные заходят по коду + паролю (или по ссылке-приглашению `…/#КОД`).
- Хост расставляет игроков по кругу и выбирает, кому загадываем: **тому, кто ниже**, **тому, кто выше** или **случайно** (случайный круг — каждый загадывает ровно одному и получает ровно одно слово).
- В раунде: своё слово скрыто, чужие видны; очередь вопросов («Передать ход»), «Я угадал!» / «Сдаюсь», места по порядку угадывания, личные заметки.
- Зашёл посреди раунда — слово ему может вписать любой. Обновил страницу или телефон уснул — вернёшься в то же лобби со своим словом.

## Техника

Бэкенда нет: статичный сайт на GitHub Pages, браузеры синхронизируются через публичные MQTT-брокеры (EMQX и HiveMQ одновременно, для надёжности) по WebSocket. Всё, что уходит в брокер, шифруется AES-GCM ключом из пароля лобби (PBKDF2), поэтому без пароля сообщения не прочитать. Лобби хранится в retained-сообщениях и истекает через 3 дня.

Скрытие своего слова — на совести игроков: технически подкованный игрок может достать его через DevTools.

Файлы: `index.html`, `style.css`, `app.js`, `vendor/mqtt.min.js` (mqtt.js 5.16.1).

Локально: `npx serve .` (или любой статический сервер) — нужен `http://localhost`, т.к. WebCrypto работает только в защищённом контексте.
